# Icon source

Harmony Git Bash uses the original Git for Windows application artwork for both
the HarmonyOS application icon and the EntryAbility window/start icon.

- Upstream repository: `https://github.com/git-for-windows/build-extra`
- Upstream path: `git.ico`
- Upstream blob: `a1ce7f6d25dacbb53ad272e09426ec791d25b19d`
- Original ICO SHA-256:
  `a9dcba5aebc93ae7aacdee03275780fc6c0f15e88fda30c93041e75851e75090`
- Adapted PNG SHA-256:
  `0ef407c161e77f2afb87e99401f6e1997ba4c414330060302d322905ecdc8fb6`

The 256x256 transparent frame was extracted and converted to PNG for HarmonyOS
resource compatibility. Its artwork, geometry, colors and transparency were not
redesigned.
